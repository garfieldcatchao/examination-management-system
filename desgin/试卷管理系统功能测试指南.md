## 🎯 测试步骤

### 智能组卷测试
1. 点击"智能组卷"Tab
2. 不填写试卷名称，点击"预览配置" → 应显示警告
3. 填写试卷名称和学科，点击"预览配置" → 显示预览弹窗
4. 点击"保存草稿" → 显示加载状态和成功提示
5. 点击"生成试卷" → 显示进度条和结果弹窗

### 导入试卷测试
1. 点击"导入试卷"Tab
2. 不选择文件，点击"开始导入" → 显示警告
3. 点击"选择文件"按钮 → 打开文件选择器
4. 选择文件后 → 显示文件信息
5. 点击"开始导入" → 显示导入进度和结果

### 模板管理测试
1. 点击"模板管理"Tab
2. 点击"新建模板" → 显示创建表单
3. 填写表单信息，点击"保存模板" → 显示加载和成功提示
4. 点击"导出模板"（不选择） → 显示警告
5. 点击模板操作按钮 → 相应功能正常执行
